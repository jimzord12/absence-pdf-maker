## Text Wrapping in Personal Details Summary Section (read-only for the user)

The fields in the "Personal Details" section need to use text wrap. If the user enters a long name, address, or other details, the text should wrap within the input box instead of overflowing or being cut off. This will improve usability and ensure that all entered information is visible to the user.

## Absence Days Calculation Section

This should exist from the start as the UI Layout is swifted when it appears only after selecting leave dates.
The section should be visible at all times to provide a consistent user experience. Use a '—' to indicate no data when no dates are selected.
