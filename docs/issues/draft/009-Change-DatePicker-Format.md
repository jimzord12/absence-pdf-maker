This application is mainly used by Greek users, so the date format in the DatePicker components should be changed from the current "MM/DD/YYYY" to the more familiar "DD/MM/YYYY" format. This change will enhance user experience by aligning with local conventions.

This should depend on the selected locale (available 'gr' and 'en'), defaulting to "DD/MM/YYYY" for Greek and "MM/DD/YYYY" for English.
