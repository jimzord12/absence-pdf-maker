## Description

Add dark: variant classes to all shared UI components (Button, Input, Card, Modal, Alert) for dark mode support.

## Constraints

- Must be completed after create-theme-store-and-provider
- Must update all shared UI components
- Must use semantic color variables (not hardcoded colors)
- Must ensure contrast ratios meet WCAG AA in both themes

## Acceptance Criteria

- Button component updated with dark: variants
- Input component updated with dark: variants
- Card component updated with dark: variants
- Modal component updated with dark: variants
- Alert component updated with dark: variants
- All other shared UI components updated with dark: variants
- Interactive states (hover, focus, active) work in both themes
- All components render correctly in dark mode
- Visual inspection shows proper dark mode styling
