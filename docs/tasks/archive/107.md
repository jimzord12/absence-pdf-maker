## Description

Create separate Zustand store for PDF language control, independent of global UI language.

## Constraints

- Follow existing store patterns from leaveRequest.store.ts and locale.store.ts
- Support 'en' and 'gr' language options
- Default to 'gr' (Greek for official documents)
- Use persist middleware with partialize
- Export inferred PdfLanguageStoreType

## Acceptance Criteria

- src/features/leave-request/state/pdfLanguage.store.ts created
- Store has pdfLanguage state (default: 'gr')
- Store has setPdfLanguage action
- Persist configured with name: 'pdf-language-storage'
- Partialize preserves only pdfLanguage
- PdfLanguageStoreType exported and inferred
