# Shared Components Context

## Overview
Reusable UI primitives and utility libraries used across the application.

## UI Primitives
- Located in `src/shared/ui/`.
- Each component should be self-contained in its own folder with an `index.ts` or the component file.
- Use Tailwind CSS for styling.
- Follow accessibility best practices (ARIA labels, keyboard navigation).

## Libraries
- `src/shared/lib/`: Contains generic utilities (date formatting, string manipulation, etc.).
- Keep utilities pure and side-effect free.
